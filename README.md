# Quickbot

**Быстрый, минималистичный и открытый ИИ-ассистент для Android.**

Quickbot создан для тех, кому нужен быстрый доступ к ИИ без лишней мишуры, привязки к Google-сервисам и сложных настроек. Это личный проект, который вырос в полноценный инструмент.

## ✨ Особенности

- 🚀 **Быстрый запуск**: Открывается жестом ассистента в виде компактного оверлея поверх других приложений.
- 🎨 **Material You / Material 3**: Поддержка динамических цветов на Android 12+, а также 7 встроенных палитр (Монохром, Мята, Индиго и др.) для более старых версий.
- 🔒 **Безопасность**: Ваш API-ключ хранится только на устройстве в зашифрованном виде (`EncryptedSharedPreferences`).
- 📝 **Markdown**: Полноценный рендеринг ответов ИИ (заголовки, списки, код, таблицы).
- 📋 **Копирование**: Долгое нажатие на любое сообщение (включая свои и ошибки) копирует его в буфер обмена.
- 📱 **Адаптивность**: Приложение оптимизировано для телефонов и планшетов.
- 🚫 **Без GMS**: Работает на устройствах без сервисов Google (Проверено на crDroid без GMS).

## 🛠 Технологии

- **Язык**: Kotlin
- **UI**: Jetpack Compose (Material 3)
- **Сеть**: OkHttp, OpenRouter API
- **Архитектура**: MVVM (ViewModel + StateFlow)
- **Сборка**: Gradle (Kotlin DSL)

## 📲 Установка

1. Скачайте последний APK из раздела [Releases](https://github.com/madcreeepyman/quickbot/releases).
2. Установите на устройство (Android 7.0+).
3. При первом запуске введите ваш API-ключ от [OpenRouter](https://openrouter.ai/keys).
4. (Опционально) Назначьте Quickbot приложением-ассистентом в настройках системы, чтобы вызывать его жестом.

## ⚙️ Настройка

- **Модель**: По умолчанию используется `openai/gpt-4o-mini`. Вы можете изменить её в настройках приложения (например, на бесплатную `openai/gpt-oss-120b:free`).
- **Оверлей**: Для работы жеста ассистента необходимо разрешение «Отображение поверх других приложений».
- **VPN**: Для пользователей из РФ может потребоваться VPN (OpenRouter блокируется провайдерами).

## 🤖 Честно об ИИ

Мне нечего скрывать, поэтому скажу честно: этот проект написан с помощью ИИ-ассистента. Под моим присмотром, с моими архитектурными решениями, тестированием на реальных устройствах и вниманием к UX. Кодинг — не моя основная профессия; это хобби-проект, который я собирал в свободное время, изучая всё по ходу дела.

Quickbot с самого начала был личным приложением для себя. В открытый доступ я выложил его только потому, что сам искал подобное и не нашёл — может, кому-то ещё пригодится.

Если вам не нравится ИИ-кодинг — это нормально, никто не заставляет устанавливать. Если нашли баг или есть идея — я открыт к здоровой критике и обсуждению.
